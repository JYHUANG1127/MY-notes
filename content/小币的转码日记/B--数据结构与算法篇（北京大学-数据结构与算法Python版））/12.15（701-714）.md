6. 词梯问题，图的应用之一：相邻的两个单词之间只能差一个字母，比如![[Pasted image 20251215101149.png]]我们的目标是找到最短的单词变换序列，采用图解决的步骤如下：将可能的单词之间的演变关系表达为图，采用BFS广度优先搜索，来搜寻从开始单词到结束单词之间的所有有效路径，选择其中最快到达目标单词的路径。
7. 首先构建单词关系图，将大量的单词集放入graph中。最简单的思路是先将单词作为顶点加入graph中，然后将单词与其他所有单词进行对比，如果只差一个字母就构成一条边，而且这边还是无权重无向的。其复杂度为n平方。在此基础上的优化是，先创建大量的桶，桶的标记是去掉一个字母，用_来替代空的字母，然后将所有匹配的单词都放到这个桶里，然后在一个桶里的单词之间建立边即可![[Pasted image 20251215102001.png]]![[Pasted image 20251215102111.png]]
8. 然后是实现BFS广度优先搜索：给定图G和起点S，搜索所有从S可到达顶点的边，在到达更远的距离K+1的顶点之前，BFS会找到全部距离为K的顶点，BFS能够保证在增加层次之前，添加所有兄弟节点。为了跟踪顶点加入的过程，避免重复顶点，给顶点添加三个属性，距离distance，从起始顶点到此顶点的路径长度，前驱顶点predecessor，可反向追溯到起点，颜色color，标识了此顶点是尚未发现（白色），已经发现（灰色），还是已经完成探索（黑色）。还需要一个queue来对已经发现的顶点进行排列
9. 首先，从起始顶点S开始，作为刚刚发现的顶点，标注为灰色，距离为0，前驱为none，加入队列，然后就是迭代过程：从队首取出一个顶点作为当前顶点，遍历当前顶点的邻接顶点，如果是白色，则改成灰色，距离加一，前驱顶点变成当前顶点，加入到queue中，如果是黑色，则跳过不做处理。遍历完成后，将当前顶点设为黑色，循环回到步骤1的队首取当前顶点。BFS的复杂度是V+E![[Pasted image 20251215103819.png]]![[Pasted image 20251215103926.png]]![[Pasted image 20251215103942.png]]

12. 另一种解决骑士周游问题的算法，深度优先搜索DFS，它的特点是逐层建立搜索树，沿着树的单支尽量深入向下搜索，如果无法继续还未找到解，就回到上一层，选另外的分支
13. 用DFS解决的思路是：如果沿着单支深入搜索到无法继续时（也就是所有合法移动都已经被走过时）,就清除颜色标记，回到上一层选其他分支，可以引入一个栈来记录路径并实施返回上一层的回溯操作![[Pasted image 20251215105438.png]]
14. warnsdoff算法，对上述算法进行优化，因为复杂度太高了，是指数级。这个算法唯一的区别，就是修改了遍历下一格的次序，它的底层逻辑是，具有最少合法移动目标的格子优先搜索，而原算法中，对搜索格子的次序无所谓,这能够加快搜索的逻辑是让计算机先跑到周边的格子，然后在回到中间的格子，这样就能加速遍历，简单的来说就是利用一些方法使得计算机少走弯路，也叫启发式规则，利用先验的只是来改进算法性能![[Pasted image 20251215110021.png]]
15. 通用的DFS。前面的DFS它一条路径中一个顶点只能经历一次，这里的DFS中每个顶点都可以多次经过。通用的深度优先搜索目标是在图上进行尽量深的搜索，连接尽量多的顶点，在必要的时候可以进行分支，创建一个树，它和之前的DFS相比，还额外设置了发现时间（灰色）和结束时间的属性（黑色），还增加了time来记录算法执行的步骤数目，其复杂度同样也是E+V![[Pasted image 20251215111207.png]]

17. 利用图来解决强连通分支：一个网站会包含一些超链接，指向其他的网站，所有这种网站就构成了一个大的图，在图中找到高度聚集节点群（某些同类网站的聚集）的算法，就是寻找“强连通分支”算法。强连通分支，定义为图G的一个子集C，C中任意两个顶点之间都有路径来回，而且C是具有这样性质的最大子集。这里利用了转置的概念transposition，G的转置，就是将图G的所有边的顶点交换次序![[Pasted image 20251215113254.png]]
18. 下面的强连通分支算法叫Kosaraju算法：首先对图G调用DFS算法，为每个顶点计算结束时间然后将图G进行转置，得到GT，再对GT进行DFS算法，但再DFS函数中，对每个顶点的搜索循环中，要以顶点的结束时间的倒序的顺序来搜索，这样得到的每一颗树都是一个强连通分支
19. 利用图来解决最短路径问题：我们可以通过在终端输入’traceroute.网站‘来追踪一个网站信息传递的路径。如果我们把路由器当成图中的节点，路由器之间的网络连接作为边，把互联网表示成一个带权重的图，一个边权重越大，就说明从一个节点（路由器）到另一个节点（路由器）的代价越高，解决信息在路由器网络中选择传播路径最快的问题就转变为带权图上最短路径问题
20. 解决带权图的最短路径问题的最经典的算法是Dijkstra算法，接近于BFS，但是在顶点的成员中多了个dist来记录传播路径中积累的权重，然后对每个顶点都迭代一次。其的复杂度是（V+E）logV（ps，该算法不能出现负数权重，否则会陷入无限循环而且需要直到整个图的所有数据，不太适合互联网，因为不可能知道所有的路由器信息，根据这个问题，考虑的是“距离向量路由算法”）![[Pasted image 20251215131821.png]]
21. 利用图来解决最小生成树问题：在上面的最短路径问题中，一个路由器的信息只会传给下一个路由器，但是有很多情况下是需要一次传给多个目标的，比如游戏中的广播，群发邮件
22. 最简单的处理传播的算法就是单播解发，广播源保存一个接收者的列表，然后每个都求最短路径问题，但是会导致某些路由器反复发送，造成浪费。
23. 另一种解法是洪水解法，广播源把消息传给它的路由器，然后每个路由器都给它连接的路由器传播一次，为了防止无限循环，可以设置一个生命值TTL，传播的最远距离，然后每传播一次都减小
24. 解决这种广播的最优的解法自然是带权图的最小生成树算法。图G（V，E）的最小生成树T，定义为包含所有顶点V的无圈子集，并且边权重最小，且在这个广播传递的过程中每个路由器都只发送一次。求最小生成树的算法叫Prim算法，它的思路是，如果T还不是生成树，就找到一条权重最小的可安全添加的边，加入这棵树，可以安全添加，就是一端顶点在树中，另一端不在树中，以便保持无圈特性![[Pasted image 20251215134943.png]]
