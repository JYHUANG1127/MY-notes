```python
class Solution:

    def detectCycle(self, head: ListNode) -> ListNode:

        slow = fast = head

        # 步骤1：找快慢指针的相遇点

        while fast and fast.next:

            slow = slow.next

            fast = fast.next.next

            if slow == fast:

                # 步骤2：找入环点

                fast = head

                while slow != fast:

                    slow = slow.next

                    fast = fast.next

                return slow

        # 无环则返回None

        return None
```
豆包的思路是先用快慢指针判断是否有环，如果有环的话就重置fast，让他变成head，并且步数为1，slow同样，然后继续走，当他们再次相遇的节点就是入环点。重置后再次相遇的节点是入环点的数学推导如下：
假设链表头到入环点距离为a
入环点到快慢指针相遇的距离为b
环的长度为c
当慢指针刚刚进入环时，走了a步，此时快走了2a步，也就是在环内走了a步，此时快慢指针都在环内，最大距离就是c-1，而因为快指针每次比慢指针多走一步，就是说在环内最多需要c-1步就追上慢指针，而c-1步之后慢指针一定还在环内。所以快慢指针相遇时。慢指针一定走了a+b步，而快指针走了a+b+kc步，k是绕环的圈数，且a+b+kc = 2*(a+b),化简得a = kc - b。快指针重置到表头，从head到入环点需要a步，慢指针走a步之后是位于a+b+a=2a+b=2kc-2b+b=2kc-b,也就是绕了2k圈之后再回退b步，刚好也在入环点。

```python
class Solution:
    def mergeTwoLists(self, list1: ListNode, list2: ListNode) -> ListNode:
        # 虚拟头节点（核心优化点）
        dummy = ListNode(-1)
        curr = dummy  # 移动指针
        
        # 遍历两个链表，拼更小的节点
        while list1 and list2:
            if list1.val <= list2.val:
                curr.next = list1
                list1 = list1.next
            else:
                curr.next = list2
                list2 = list2.next
            curr = curr.next
        
        # 拼接剩余节点（无需判断，直接拼非空的）
        curr.next = list1 if list1 else list2
```
