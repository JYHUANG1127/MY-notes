但是额外空间不满足条件，是O(n)级别
豆包的代码：
```python
class Solution:

    def firstMissingPositive(self, nums: List[int]) -> int:

        n = len(nums)

        # 步骤1：原地重排数组，将正整数x放到x-1的索引位置

        for i in range(n):

            # 循环交换：确保当前位置的正整数x被放到正确位置（x-1）

            # 条件说明：

            # 1. 1 <= nums[i] <= n：只处理范围内的正整数，超出范围的数不影响结果

            # 2. nums[nums[i] - 1] != nums[i]：避免重复交换（当x已经在正确位置时停止）

            while 1 <= nums[i] <= n and nums[nums[i] - 1] != nums[i]:

                # 交换nums[i]和nums[nums[i]-1]，将x放到正确位置

                target_index = nums[i] - 1

                nums[i], nums[target_index] = nums[target_index], nums[i]

        # 步骤2：遍历数组，找到第一个缺失的正整数

        for i in range(n):

            if nums[i] != i + 1:

                return i + 1

        # 步骤3：若1~n都存在，返回n+1

        return n + 1
```
