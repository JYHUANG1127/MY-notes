```python
if not intervals:
            return []
        
        # 按区间起始位置排序
        intervals.sort(key=lambda x: x[0])
        res = [intervals[0]]
        
        for curr in intervals[1:]:
            last = res[-1]
            # 只有当前区间的start <= 上一个区间的end，才合并
            if curr[0] <= last[1]:
                last[1] = max(last[1], curr[1])
            else:
                res.append(curr)
        return res
```
先判断是否是空集，如果给的数组是空集，直接返回空集。然后把区间按找起始位置排好序，这里的写法包括以key=起始位置（这是sort函数的可选参数）来排序，然后求起始位置用了一个匿名函数lambda，x是这个数组中的每一个元素，返回的是x[0]，也就是起始位置。然后首先令res这个列表包含了intervals的第一个元素列表，然后从intervals的第二个元素开始遍历，令last=res[-1]是指last是res中最后一个元素，如果被遍历的list的start小于等于上一个区间的end，就合并，否则就直接加入res中。这里不太需要排斥使用sort，复杂度已经不算高了。
