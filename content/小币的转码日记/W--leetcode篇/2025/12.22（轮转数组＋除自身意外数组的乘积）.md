``` python
def rotate(nums, k):
    n = len(nums)
    k %= n  # 处理k超过数组长度的情况
    # 辅助函数：反转数组的[left, right]区间
    def reverse(left, right):
        while left < right:
            nums[left], nums[right] = nums[right], nums[left]
            left += 1
            right -= 1
    reverse(0, n-1)    # 反转整个数组
    reverse(0, k-1)    # 反转前k个元素
    reverse(k, n-1)    # 反转剩余元素
```

```python
class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        n = len(nums)
        answer = [1] * n  # 初始化结果数组
        
        # 第一步：计算前缀积（左侧所有元素的乘积）
        for i in range(1, n):
            answer[i] = answer[i-1] * nums[i-1]
        
        # 第二步：计算后缀积（右侧所有元素的乘积），并与前缀积相乘
        suffix = 1  # 维护右侧元素的乘积
        for i in range(n-1, -1, -1):
            answer[i] *= suffix
            suffix *= nums[i]
        
        return answer
```
利用前缀积和后缀积的方法，遍历两边数组，首先从前遍历到后面，计算前缀积，也就是在i左侧所有元素的乘积，然后从后遍历到前面，在维护右侧元素的乘积，suffix记录右侧的积。
