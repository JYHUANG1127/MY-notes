```python
class Solution:

    def addTwoNumbers(self, l1: Optional[ListNode], l2: Optional[ListNode]) -> Optional[ListNode]:

        pre = ListNode(0)  # 虚拟头节点

        cur = pre

        carry = 0  # 进位

        while l1 or l2 or carry:

            # 取当前节点值（空则为0）

            val1 = l1.val if l1 else 0

            val2 = l2.val if l2 else 0

            # 计算当前位总和与进位

            total = val1 + val2 + carry

            carry = total // 10  # 进位（0或1）

            cur.next = ListNode(total % 10)  # 当前位结果

            # 移动指针

            cur = cur.next

            if l1:

                l1 = l1.next

            if l2:

                l2 = l2.next

        return pre.next  # 虚拟头的next是结果头
```
思路就是先用一个虚拟头，然后从个位开始加，如果大于10 就计录在carry上，然后加到下一项，当其中一条链表取完之后则取0，直到两条都遍历结束，carry = total//10是更新它的进项。
