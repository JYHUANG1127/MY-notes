```
from collections import deque

        q = deque()

        res = []

        for i, num in enumerate(nums):

            # 1. 维护队列：把比当前元素小的都弹出（这些元素不可能成为后续窗口的最大值）

            while q and nums[q[-1]] < num:

                q.pop()

            q.append(i)

            # 2. 检查队首元素是否超出当前窗口（窗口左端是 i-k+1）

            while q[0] <= i - k:

                q.popleft()

            # 3. 窗口长度达到k后，开始记录最大值（队首）

            if i >= k - 1:

                res.append(nums[q[0]])

        return res
```
这里的思路是使用双端队列deque来存储流动窗口内可能成为最大值的元素的索引，队列内元素对应的数值严格递减，所以在新元素入队前，先把队列里比它小的元素全部弹出，同时检查队首元素是否超出当前窗口范围，超出则弹出，窗口长度达标后，队首元素就是当前窗口的最大值。
最关键的思路是比当前要加入的元素要小的元素，是不可能成为当前窗口或者后续窗口的最大值的，因为有比你大的元素加入了，这样就可以保证每个元素在操作时最多只有两个步骤，加入deque和弹出deque
