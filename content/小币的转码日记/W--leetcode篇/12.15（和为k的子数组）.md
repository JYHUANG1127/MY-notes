正确思路是用前缀和加哈希表的思路来解决
对于数组nums，前缀和pre_sum[i]的定义表示从nums[0]到nums[i-1]的累加和，如果是pre_sum[0]，就是0，是空数组的和
任意连续的子数组的nums[j...i-1]的和就等于pre_sum[i] - pre_sum[j]
要找和为k的子数组，就是找pre_sum[j]=pre_sum[i] - k，意味着遍历到pre_sum[i]时，只要统计前面出现过多少次 `pre_sum[i]-K`，就有多少个以 `i-1` 结尾的、和为 K 的连续子数组。
这部分的解释关键在于这个子数组必须是连续的，如果`pre_sum[i]-K`等于了`pre_sum[j]’
就说明j到i之间的元素和为k，所有出现了多少此，就有多少个子数组，用哈希表储存的就是`pre_sum[j]'
```python
def subarraySum(nums, k):
    # 哈希表：key=前缀和，value=该前缀和出现的次数
    sum_count = {0: 1}
    current_sum = 0  # 实时计算当前前缀和
    result = 0       # 记录符合条件的子数组数量
    
    for num in nums:
        current_sum += num  # 累加当前元素，更新前缀和
        # 核心：找前面有多少个 pre_sum = current_sum - k
        target = current_sum - k
        if target in sum_count:
            result += sum_count[target]
        # 更新哈希表：当前前缀和的出现次数（存在则+1，不存在则设为1）
        sum_count[current_sum] = sum_count.get(current_sum, 0) + 1
    
    return result
```
在这里还使用了哈希表来储存前缀和出现的次数，sum_count = {0: 1}表示`pre_sum[0]=0` 出现 1 次，遍历数组时，逐步计算当前前缀和 `current_sum`，并统计 `current_sum - K` 在 `sum_count` 中的次数，累加到结果中，最后将当前 `current_sum` 加入 `sum_count`（更新出现次数）
