```python
class Solution:

    def getIntersectionNode(self, headA: ListNode, headB: ListNode) -> Optional[ListNode]:

        pA, pB = headA, headB

        # 当pA和pB未相遇时循环

        while pA != pB:

            # pA遍历完A则切换到B，否则走下一个节点

            pA = pA.next if pA else headB

            # pB遍历完B则切换到A，否则走下一个节点

            pB = pB.next if pB else headA

        # 相遇时返回（可能是相交节点，也可能是None）

        return pA
```
这题的思路是利用双指针解决，先初始化pA=head A, pB = head B.然后以pA，pB不相遇为条件进行while循环，然后直到他们相遇。设a是headA中独有的长度，b是headB中独有的长度，c是他们共有的长度，每一次while循环，pA，pB都走一步，他们走的步数是相同的，当结束循环的时候，应该是pA走到B中的交叉节点，pB走到A中的交叉节点，因为他们的长度不一样，当pA或者pB第一次到自己的节点时不一定对边的指针也刚好是交叉节点，但是遍历完之后一定是。此时pa的值就是他们的交点，如果不是，就会跑到末尾变成null。
```
这里的写法很节省，pA = pA.next if pA else headB,它真实意思是如果pA不是none，就让pA =pA.next,如果pA遍历了整个A，则变成了none，这个时候就触发else，pA变成了headB了，再遍历B，pB同理，且如果没有交点，也不用担心会无限循环，因为pA，pB此时都是none，还是符合结束循环的语句
```
