```
class Solution:

    def maxSubArray(self, nums: List[int]) -> int:

        max_sum = current_sum = nums[0]

        # 从第二个元素开始遍历

        for num in nums[1:]:

            # 核心：当前子数组和 = max(当前元素本身, 前序子数组和+当前元素)

            # 若前序子数组和为负，直接舍弃，从当前元素重新开始

            current_sum = max(num, current_sum + num)

            # 更新全局最大值

            max_sum = max(max_sum, current_sum)

        return max_sum
```
这个解法的逻辑是当选择一个元素是，是否要带上前面的连续子数组，如果前面的为正，就加上，如果为负，就不加。然后比较现在的最大值和历史的最大值之比，取最大值。
因为current_sum就代表着以这个num结尾的所有子数组中，和最大的值。
比如遍历到元素 `4`（数组 `[-2,1,-3,4]`）时，「以 4 为结尾的子数组」只有以下几种可能：

- `[4]`（和 = 4）
- `[-3,4]`（和 = 1）
- `[1,-3,4]`（和 = 2）
- `[-2,1,-3,4]`（和 = 0）
其中最优解是 `4`，这就是此时 `current_sum` 的值。用递推的逻辑解释就是，假设遍历到第 `i` 个元素 `num` 时，`current_sum` 已经是「以第 `i-1` 个元素结尾的最优子数组和」，那么「以第 `i` 个元素结尾的最优子数组和」只有两种选择，选择 1：把第 `i` 个元素接在「以 `i-1` 结尾的最优子数组」后面，对应的和 = `current_sum（i-1的最优） + num`。选择 2：放弃所有前面的子数组，只取第 `i` 个元素本身，对应的和 = `num`。然后比较的结果就是以第i个元素结尾的最优解。
