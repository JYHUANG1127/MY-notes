```python
class Solution:
    def findAnagrams(self, s: str, p: str) -> List[int]:
        res = []  # 存储结果（异位词的起始索引）
        len_s, len_p = len(s), len(p)
        if len_s < len_p:  # 如果s比p短，不可能有异位词 → 直接返回空列表
            return res
        
        # 1. 统计p中每个字符的出现次数（用长度26的数组，对应a-z）
        p_count = [0] * 26
        for char in p:
            # ord(char)-ord('a') → 把字符转成0-25的索引（a→0, b→1,...z→25）
            p_count[ord(char) - ord('a')] += 1
        
        # 2. 初始化“滑动窗口”的字符计数（先统计s的前len_p个字符，即第一个窗口）
        window_count = [0] * 26
        for i in range(len_p):
            window_count[ord(s[i]) - ord('a')] += 1
        
        # 3. 检查第一个窗口是否是异位词
        if window_count == p_count:
            res.append(0)  # 第一个窗口的起始索引是0
        
        # 4. 滑动窗口：从第len_p个字符开始，逐个移动窗口
        for right in range(len_p, len_s):
            # 窗口右移：移除窗口最左边的字符（left_char）
            left_char = s[right - len_p]  # 窗口左边界的字符
            window_count[ord(left_char) - ord('a')] -= 1  # 左字符次数-1
            
            # 窗口右移：加入新的右字符（new_char）
            new_char = s[right]
            window_count[ord(new_char) - ord('a')] += 1  # 新字符次数+1
            
            # 检查当前窗口是否是异位词
            if window_count == p_count:
                # 当前窗口的起始索引是：right - len_p + 1
                res.append(right - len_p + 1)
        
        return res
```
解决这题的思路是滑动窗口，用长度为len（p）的滑动窗口再s上移动，通过统计窗口内字符出现的次数就可以判断它们是否是字母异位词。其中最关键的就是怎么统计窗口内字符出现的次数，这里的思路是
