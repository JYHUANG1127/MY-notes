```python
class Solution:

    def levelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:

        res = []

        c = 0 #记录层数，加入res的第c个元素中

        def level_order(node):

            nonlocal c

            if not node:

                return

            if c > len(res) - 1:

                res.append([node.val])

            else:

                res[c].append(node.val)

            c += 1

            level_order(node.left)

            level_order(node.right)

            c -=1

            return

        level_order(root)

        return res
```
我的思路就是用c来记录层数，然后遍历整个数组就行，但是我的是深度优先，只是取了个巧，利用c来添加了，正确的应该是广度优先搜索，深度优先的意思是往左子树或者右子树一门心思的走到底（对应递归的结束条件），而广度的意思是把一个二叉树的一层全部遍历之后，再下一层
```python
class Solution:

    def levelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:

        from collections import deque  # 官方推荐的高效队列库

        res = []

        # 1. 特殊情况：根节点为空，直接返回空列表

        if not root:

            return res

        # 2. 初始化队列，把根节点加入队列（队列里存的是“当前层的节点”）

        queue = deque([root])

        # 3. 循环处理每一层：只要队列不为空，就还有层要处理

        while queue:

            # 记录当前层的节点数量（关键！保证只处理当前层的节点）

            level_size = len(queue)

            # 存储当前层的所有节点值

            current_level = []

            # 4. 遍历当前层的所有节点

            for _ in range(level_size):

                # 取出队列头部的节点（先进先出）

                node = queue.popleft()

                # 把当前节点值加入当前层的列表

                current_level.append(node.val)

                # 5. 把当前节点的左右子节点（下一层节点）加入队列

                if node.left:

                    queue.append(node.left)

                if node.right:

                    queue.append(node.right)

            # 6. 把当前层的结果加入最终结果

            res.append(current_level)

        return res
```
我对这个广度搜索的理解是利用了deque先进先出的特点，同样也是遍历整个二叉树，只是在处理当前层的节点时，还同时把下一层的节点按照相同的顺序也存进对应层数的队列中，然后处理下一层刚刚完成的队列时，同时又把下下一层的节点按照顺序存入deque中
我以为这种每一层都构建一个deque来临时存储下一层节点会占据更对空间，而我之前深度搜索的代码不需要除了res额外的空间，空间复杂度一个更小，但是豆包说因为python，它会有隐式的递归调用栈的额外空间，在调用栈中，python的递归会保存每一层递归的上下文，也就是有很多层的环境是同时存在的，所以占用空间大，而广度搜索，从上往下，顶多是这一层和下一层的deque存在额外空间
