```python
class Solution:

    def inorderTraversal(self, root: Optional[TreeNode]) -> List[int]:

        result = []

        def traverse(node):

            if not node:

                return

            traverse(node.left)

            result.append(node.val)

            traverse(node.right)

        traverse(root)

        return result
```
在这里使用了递归算法，中序遍历的要求是先找到整个二叉树结构中的最左端，然后再遍历到最左端的根节点，然后以这个根节点的右节点为新的根节点，继续找到最左点
在traverse函数中，判定条件就是找到了空节点，如果输入的是非空节点，就会自动对这个非空节点调用traverse函数，一层层的迭代下去，一旦最后一层的node.left为空了，在该层就return了，然后这个节点就是最左端的点，直接加入result中，在对node.right进行traverse函数，找到以right为根节点的最左端节点，假设这个时候node.right就是null，就会直接返回上一层的traverse(node.left)，然后在进行result.append(node.val)
以root=[1,null,2,3]为例
第一层：首先对1进行traverse函数调用，1不是空节点，然后对1的左节点调用traverse函数
第二层：1的左节点为空，直接返回，这层空间结束，回到第一层，执行append函数将这个节点的值加入result中，然后对1的right调用traverse函数
第二层：1的right，也就是2，非空，对1的right的left，也就是3，调用traverse函数
第三层：3非空，对3的left调用traverse函数
第四层：3的left为空，直接返回，这层空间结束，回到第三层
第三层：对3进行append，然后对3的right调用traverse函数
第四层：3的right为空，直接返回，这层空间结束，回到第三层
至此，第三层的traverse函数运行结束，自动return
第二层：对2进行append，然后对2的right进行traverse函数
第三层：2的right为空直接返回
第二层：traverse函数运行结束，返回第一层
第一层：第一层的traverse函数也运行结束
也就是traverse（root）运行结束，此时result就是中序遍历的结果

递归的三要素是
1. 终止条件，确定递归的终点，结束这层空间
2. 递归拆解：把大问题拆成小问题（这里就是把大的二叉树拆成小二叉树，一直到最后一个单纯的节点）
3. 处理当前层：执行当前节点的核心操作
