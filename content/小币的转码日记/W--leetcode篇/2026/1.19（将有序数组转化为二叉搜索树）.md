```python
class Solution:

    def sortedArrayToBST(self, nums: List[int]) -> Optional[TreeNode]:

        def build_bst(left, right):

            if left > right:

                return None

            mid = (left + right) // 2

            root = TreeNode(nums[mid])

            root.left = build_bst(left, mid - 1)

            root.right = build_bst(mid + 1, right)

            return root

        return build_bst(0, len(nums) - 1)
```
二叉搜索树，是指对于任意一个节点，左子树小于该节点，右子树大于该节点，平衡特性是控制树的高度，避免出现链表化的极端情况
为了平衡特性，这里是兼顾数组中间位置的元素当根节点，这样左右子数组的长度要么相等，要么相差1。
然后就是因为这是有序数组，此时左半部分都小于中间元素，右半部分都大于中间元素，然后就是把它们放入二叉树中。
首先是递归函数的结束条件，左边界大于右边界，直接返回。然后是什么时候调用自身，也就是构建左子树和右子树的时候调用自身，然后是函数主体部分，先选取中间点，并将它看成根节点，然后构建左子树，也就是调用自身，只是left和right变化了，构建右子树，这里并不需要下一层的返回值作为输入，因为只要放入树中即可，然后这里的返回值其实只用到了第一层的返回值，也就是总的根节点，是为了返回给整个的函数
