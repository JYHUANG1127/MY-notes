1. 整数部分的转换：（十进制到二进制）以19为例，19/2=9，余1，9/2=4，余1，4/2=2，2/2=1，1/2=0，余1，则二进制为10011，看余数，余数为0就是0，余数不为0，则为1，直到最终除法结果为0.（从二进制到十进制）1✖2的四次方＋0✖2的3次方＋50✖2的二次方＋1✖2的1次方加1乘以2的0次方。
2. 小数部分：（二进制转换为十进制）在2进制里为0.abc的数，在10进制里为a✖2的-1次方＋b✖2的-2次方＋c✖2的-3次方。（十进制转换为二进制）最重要的是找到一个2的幂指数值，使得该数✖这个值时，能够刚好成为整数，然后用整数的方法转换，接着移动幂指数位即可
3. 浮点数在计算机中的储存是一对整数的形式，比如31.25的储存就是（125，-2）表示125的二进制为（1111101），-2表示小数点左移2位，所以为（11111.01）然后转换为31.25，也可以直接用125✖2的-2次方。
4. 在近似中，永远不要使用等号，因为浮点数它本身就不准，必须设置一个范围。而且要额外设置一个条件来使得循环不会卡死，因为可能在整个被计算的近似值中都不存在满足的数字，就要设置一个上限来跳出循环。如果要使得程序能够跑通，可以减小每次的增量，或者增大范围。
5. 二分法在某些问题上可以大幅度减少计算的步数，比如求解一个数的平方根：从中值开始，比较大小，然后找下一个中值，循环直到进入设置的范围内。但是缺点是可能因为浮点数的不准确，导致low 和high值相同时，会陷入死循环。

以找一个数的立方根为例：

```python
x = float(input('choose a number'))
low = 0
high = x
guess = x/2
epsilon = 0.01
while abd(guess**3 - x) > epsilon:
    if guess**3 >x:
        high = guess
    else:
        low = guess
    guess = (high + low)/2
return print(f"'guess','is close to the cube root of','x'")
```
